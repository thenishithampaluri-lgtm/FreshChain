03 / ENGINEERING METHODS

Feature transformation methods

Select transformations based on data characteristics, model requirements, and validation performance.

A Categorical

One-Hot Encoding

Converts fruit categories into numerical indicator columns so the classifier can process them.

Fruit = Apple → Fruit_Apple = 1
σ Scaling

Standardization

Rescales numerical readings using statistics learned from training data. Useful for Logistic Regression.

Sensor values → Scaled values
∼ Missing Data

Median Imputation

Replaces missing numerical measurements with medians calculated from the training data.

Missing reading → Training median
ƒ Optional

Interaction Features

Candidate features can represent combinations of sensor measurements when justified by domain knowledge.

Temp × Humidity → Candidate feature

Note: interaction, logarithmic and polynomial features are optional. Keep them only if validation shows a benefit. They are not automatically applied just because they are described on this page.
