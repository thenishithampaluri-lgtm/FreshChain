01 / MODEL OVERVIEW

About the model

A transparent baseline for fruit condition classification.

What does Logistic Regression do?

Logistic Regression estimates class probabilities from input features and assigns a predicted class. In FreshChain, the inputs are fruit type and four environmental sensor readings.

The preprocessing pipeline imputes missing sensor values, encodes fruit categories, and standardizes numerical features before fitting the classifier.
